# ED1 — Algorithms Exercises C++

Repositório com exercícios e atividades da disciplina de **Estrutura de Dados I**, desenvolvidos em **C++**.

## 📂 Estrutura

```text
src/
└── main/
    └── cpp/
        └── dev/
            └── v-anjos/
                └── exercises/
                    ├── list01_algorithms/
                    └── list02_algorithms/
```

Cada pasta `listXX_algorithms` contém os exercícios correspondentes à respectiva lista de atividades.

## 🛠️ Requisitos

* C++17 ou superior
* GCC/G++
* Git

Verifique o compilador:

```bash
g++ --version
```

## 📥 Clonar o projeto

```bash
git clone https://github.com/v-anjos/ed1-algorithms-exercises-cpp.git
cd ed1-algorithms-exercises-cpp
```

## ⚙️ Compilação e execução

Entre na pasta da lista desejada:

```bash
cd src/main/cpp/dev/v-anjos/exercises/list01_algorithms
```

Compile o exercício:

```bash
g++ -std=c++17 -Wall -Wextra exercicio.cpp -o exercicio
```

Execute:

### Linux / macOS

```bash
./exercicio
```

### Windows

```powershell
.\exercicio.exe
```

## 🚀 Exemplo

cd src/main/cpp/dev/v-anjos/exercises/list01_algorithms
